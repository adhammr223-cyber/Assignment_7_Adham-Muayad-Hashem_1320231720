# Restaurant Landing Page

A restaurant page with food images and sections for presenting the restaurant and dishes.

## Technologies

HTML, CSS.

## Run locally

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Keep the existing image and stylesheet folders in place.

## Project scope

This is a static page with no ordering or booking service.
