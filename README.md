# صفحة مطعم

## التقنيات

HTML وCSS داخل الصفحة.

## فكرة المشروع

صفحة ثابتة لعرض المطعم والأطباق باستخدام الصور والأقسام المنسّقة.

## التشغيل

1. نزّل المستودع أو انسخه.
2. افتح `index.html` في متصفح حديث.
3. احتفظ بمجلدات الصور والملفات في مواقعها الحالية حتى تعمل المسارات.

## ملفات البداية

- `index.html`

## حدود المشروع

لا توجد خدمة طلبات أو حجوزات خلفية.
